# Plan: Sistema de Etiquetas Automáticas (Smart Labels)

## Visión General

Las etiquetas pasan de ser tags manuales sin propósito a un sistema
**automático basado en reglas** que el admin configura. Cada regla
evalúa datos reales (fecha de creación, visitas, favoritos) y
asigna/desasigna etiquetas a los libros automáticamente.

## 1. Base de Datos

**Nueva tabla `label_rules`:**

```sql
CREATE TABLE label_rules (
  id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  label_id BIGINT NOT NULL REFERENCES labels(id) ON DELETE CASCADE,
  rule_type TEXT NOT NULL CHECK (rule_type IN (
    'new_release',     -- libros nuevos en los últimos N días
    'most_read',       -- top N por book_views en un período
    'most_popular',    -- top N por favoritos
    'most_favorited'   -- top N por user_favorites
  )),
  params JSONB NOT NULL DEFAULT '{}',
  created_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
  updated_at TIMESTAMPTZ NOT NULL DEFAULT NOW()
);
```

**Ejemplos de params por tipo:**

| rule_type            | params                                 |
| -------------------- | -------------------------------------- |
| `new_release`        | `{"days": 30}`                         |
| `most_read`          | `{"limit": 10, "days": 30}`            |
| `most_popular`       | `{"limit": 10}`                        |
| `most_favorited`     | `{"limit": 10}`                        |

## 2. Worker (Edge Function + Cron)

Una Edge Function `sync-labels` que:

1. Recorre todas las reglas activas
2. Para cada `rule_type`, ejecuta la query correspondiente
3. Calcula qué libros deberían tener cada etiqueta
4. Sincroniza `books_labels`: agrega las que faltan, remueve las que ya no corresponden

Ejecutada por Supabase Cron (pg_cron) cada cierto tiempo.

**Lógica por tipo:**

| Tipo | Query |
| --- | --- |
| `new_release` | `books WHERE created_at >= NOW() - INTERVAL '$days days'` |
| `most_read` | Viewed in period, group by book, top N |
| `most_popular` | Books sorted by total tooks+chapters, top N |
| `most_favorited` | Favs grouped by book, top N |

## 3. Backend (Dart)

- Nuevos use cases: `CreateRule`, `UpdateRule`, `DeleteRule`, `GetRules`, `SyncLabels`
- `LabelBloc` se extiende para manejar reglas
- El worker se puede invocar manualmente desde el panel admin además del cron

## 4. UI — Panel Admin

Nuevo tab o sección "Reglas de Etiquetas":

- Lista de reglas con: nombre de la etiqueta, tipo, parámetros
- Crear regla: selector de etiqueta + tipo + params (campos dinámicos según tipo)
- Editar/Eliminar regla
- Botón "Ejecutar ahora" para forzar sync

En el **detalle del libro** (`book_detail_content.dart`), mostrar las
etiquetas automáticas con un ícono distintivo.

## 5. Prioridad de Implementación

1. Tabla `label_rules` + migración
2. Edge Function `sync-labels` con los 4 tipos de reglas
3. Cron job
4. Panel admin: CRUD de reglas
5. UI: mostrar etiquetas en detalle del libro
6. Botón "Ejecutar ahora" + feedback
